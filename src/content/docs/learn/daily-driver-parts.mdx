This is the Daily Driver as an interactive model. Drag the slider to **pull the
assembly apart and back together**, toggle the **sub-assemblies** (earcup, gimbal,
headband), or **click any part to isolate it** and inspect it on its own.

This page shows the **current build** — the latest version promoted as stable. To watch
the design change in real time as it's worked on, see the **[live beta
view](/learn/daily-driver-parts-beta/)**. It's all developed in the open at
[github.com/makerphones/daily-driver](https://github.com/makerphones/daily-driver).

The headphone is built from a small set of 3D-printed parts plus one bought metal
headband bow. Everything below is exactly what you print to make one pair: the
quantities are per complete headphone (two ears).

For sourcing the bought hardware (the bow, M3 shoulder screws, and heat-set
inserts) and rough costs, see the build's bill of materials in the
[design spec](/learn/daily-driver-design-spec/). Each printed part is a starting
point you can modify. The model is fully parametric, so changing a driver, a pad,
or the head size regenerates the parts to match.

:::note[Current build vs. live beta]
This is the **current build** — the latest version promoted as stable. The
[live beta view](/learn/daily-driver-parts-beta/) tracks the work-in-progress and updates
on every commit. Nothing is print-verified yet; some parts (the headband pad, the head
fit/kinematics) are deliberately rough drafts. Follow along, and fork freely.
:::
